## Design rules
1. The concept artwork is visual direction, not an implementation screenshot or official prayer time.
2. UI elements must be implemented as actual React Native components. Do not insert an entire concept screenshot as the screen's background.
3. The ring **itself rotates smoothly** under the finger while the 12 o'clock needle and central text remain static.
4. Labels remain upright using a counter-rotation transform.
5. Real kerahet intervals, Diyanet schedule sourcing and verified imagery rights need separate approval before release.
6. Do not ship screenshot texts/date/time as factual religious content.
