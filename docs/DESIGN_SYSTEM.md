# Design system v0.1

Visual direction: **ivory / emerald / muted gold** as light theme, **midnight navy / deep emerald** as dark theme. Reference concept art from the design discussion is visual inspiration, not a pixel-exact implementation or real-time prayer-data proof.

| Token | Hex |
|---|---|
| emerald | \`#152821\` |
| ivory | \`#F7F4ED\` |
| matte gold | \`#B69C70\` |
| midnight navy | \`#202A30\` |
| afternoon accent | \`#0FA97A\` |
| kerahet warning | \`#C45D62\` |

Do not encode information with color alone; use labels and accessibility announcements. Preserve minimum 44pt touch targets. Distinguish current time, selected time and upcoming prayer. Keep wheel labels readable at 320pt device widths. Reduce visual effects on older devices and for reduced-motion accessibility settings.

Kerahet periods shown in the artwork are illustrative only and MUST NOT be replicated as a single arbitrary time period.
